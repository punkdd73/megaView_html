1. 動態儲位 (Dynamic Storage) 運作流程

主位固定錨定與備存溢流彈性配置之雙軌機制

固定主位（老戶長）與動態溢流區

在傳統固定儲位中，若貨品入庫量超出儲格容量，現場作業員只能被迫隨意堆置走道。MegaView 採用「主位錨定 + 動態溢流」的動態架構：

  • 主揀位 (Primary Slot)：每個型號擁有唯一專屬老家，是揀貨動線上的優先取貨點。
  • 動態隨機備存位 (Chaotic Overflow)：當進貨量超出主位設計容量時，系統將依預設條件，自動將多餘貨量動態分配至任何可用的空置溢流儲格，打破固定區域限制，最大化坪效。

進貨配儲與動態回填閉環流程

入庫觸發 系統檢核主位剩餘容量：未滿則回填老家，超額自動指派溢流位。
出貨消耗 作業員優先自「主揀位」領料出庫，主揀位逐步釋出實體空間。
溢流前推 點擊「空間健康度整頓」，系統自動掃描溢流件並產生前推指引，回填主位。

3. 儲位生成規則設定（多儲格支援）

透過分倉自訂規則表，自由規劃單一位號切分多儲格之實體空間矩陣

空間生成參數定義

於 Excel 中建立倉別分頁（如 HQ、WH2），透過下列 7 大維度展開空間笛卡兒積：

  • 屬性代碼：PRIMARY (主揀位)、OVERFLOW (溢流備存位)。
  • 架號清單 (Racks)：如 A, B, C, D... 或 G, H, I, J。
  • 層號清單 (Levels)：如 1, 2, 3, 4, 5, 6 層。
  • 位號清單 (Bays)：如 01, 02, ..., 08 位。
  • 格號清單 (Slots)：如 A, B, C, D 或 A1, A2, B1, B2（即可在一位中切分多格）。
  • 容量上限 (Capacity)：單一儲格實體可容納件數（pcs）。
  • 允許溢流 (can_overflow)：設為 Y 即開放主位溢流至指定區。

內部 6 段式儲位代碼命名規範

[倉別]-[屬性]-[架號]-[層號]-[位號]-[格號]
HQ-F-A-1-01-A // 架A 1層 01位 之 A格
HQ-F-A-1-01-B // 架A 1層 01位 之 B格 (同位第2格)
HQ-P-G-6-01-A1 // 架G 6層 01位 之 A1複合格

儲位生成時，系統自動重置空置儲位之軟綁定，保留動態認主配位彈性。

6. 主系統儲位錨定與單一儲位拆解多儲位架構

在主系統單一字軌約束下，實現本地實體多格化與動態溢流

實務痛點與解決之道

為什麼需要將「主系統單一儲位」拆解為「實體多儲位」？

主系統儲位架構機制與現場需求不符，或儲位管理介面過於複雜，維護效率低下。

在現場實務上，單一儲位實體容積有限，若不採行動態儲位設計，而以靜態「型號+儲位」方式綁定，坪效使用率及抗變動能力極低。

MegaView 設計了「外持單軌、內建多格」的雙層對稱映射：

主系統系統視角（單一靜態錨定）
F-A-1-01-A 50pcs

僅辨認此基礎老戶長，不顯示動態溢流。

⬇️ MegaView 本地無損拆解 ⬇️
MegaView 實體庫房視角（多儲格 + 溢流池）
主揀位：F-A-1-01-A 10pcs (基礎老家預設10pcs)
溢流位 1：F-A-1-01-B 10pcs (設定超額上限，優先配入鄰近儲位)
溢流位 2：H-O-1-03-C 30pcs (溢流儲格動態容納所有超量)
雙贏效果：主系統始終維持單一主儲位字軌，無需頻繁配儲；而在現場庫房，作業員享有完整的多儲格切分、動態配儲與溢流前推彈性！
